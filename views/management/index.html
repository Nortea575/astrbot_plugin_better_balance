额度与余额管理

管理每日配额、余额供应商、回复文本和点歌联动；原生插件设置与本页共用一份配置。

默认配额

配额设为 -1 表示加入黑名单并禁止 LLM 请求；0 表示不限额；正整数表示每天可成功发送的 LLM 回复轮数，同一轮的工具和判断调用不重复扣次。修改重置时间会保留本期用量，并在下一个设定时刻重置。

用户组

每个 QQ 号只能属于一个用户组；组内成员各自使用该组配额，不共享用量。配额含义同上（-1 黑名单、0 不限额、正整数为每日成功发送的 LLM 回复轮数）。成员按 QQ 号填写，可用换行或逗号分隔。

群规则

为指定群设置配额，群内成员共享该群配额；未列出的群使用默认值。配额含义同上（-1 黑名单、0 不限额、正整数为每日成功发送的 LLM 回复轮数）。

余额供应商

绑定 AstrBot 供应商 ID 可多选；扫描仅读取本地配置，不发起余额请求。手动查询凭证不会从模型供应商密钥自动复制。

余额查询预览

单条查询与全部查询显示在同一结果表中；失败供应商各占一行。查询使用已保存的设置，修改记录后请先保存。
